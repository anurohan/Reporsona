# RePersona — Frontend

Cinematic Next.js 14 (App Router) client for **RePersona — AI-Powered Personality Reconstruction**.

See the root project README for the full architecture and backend setup.

## Quick start

```bash
cp .env.example .env.local   # point NEXT_PUBLIC_API_BASE at the FastAPI backend
npm install
npm run dev                  # http://localhost:3000
```

The backend (FastAPI) must be running — default `http://localhost:8000`.

## Stack

Next.js 14 · React 18 · TypeScript · Tailwind CSS · three / @react-three/fiber / drei · framer-motion · lucide-react.
